Dammer/Privacy

Privacy policy

Dammer collects nothing.

No accounts, no analytics, no advertising and no servers. Everything the extension does happens inside your browser, on your computer.

Effective 12 October 2026. Applies to Dammer 1.0.0 and later.

What Dammer can see

Dammer has the tabs permission. This lets it read the title and address of your open tabs, which it uses for two things:

  • to show your tabs in the tab picker so you can choose one;
  • to check, each time a refresh is due, that the chosen tab is still on the same site and has not been sent to a login page.

Dammer has no content scripts and no host permissions. It cannot read or change what is on any page: not text, not forms, not passwords, not cookies.

What Dammer stores

All of it stays in your browser profile on your computer.

WhereWhatKept until
Local extension storageYour settings: interval, theme, timer style and so on.You reset or remove the extension.
Local extension storageThe tab you chose: its tab number and its address without the query string or fragment (for example https://example.com/inbox, never ?token=…).You choose another tab or remove the extension.
Local extension storageThe number of the tab currently protected from Memory Saver, so the protection can be undone after an update.The timer stops.
Session storage (memory only)The running timer: tab number, address as above, start time, next refresh time and refresh count.The timer stops or the browser closes.
Popup local storageA copy of your theme and colour, so the popup opens without a flash.You remove the extension.

Dammer does not use Chrome's synced storage, so nothing is copied to your Google account.

What Dammer sends

Nothing. The extension's content security policy sets connect-src 'none', which makes the browser block every network request from the extension's own pages. The project's automated check also fails if networking code is ever added.

Reloading a tab does cause your browser to request that page from its website again, exactly as pressing the reload button would. That request goes from your browser to the site, not through Dammer.

The About page inside the extension links to the developer's GitHub and LinkedIn profiles. They open in a new tab only if you click them.

Other permissions

  • alarms: to wake the extension when a refresh is due.
  • storage: for the items in the table above.
  • idle: to learn whether the computer has been used recently, for the "On the tab" and "Stop if away" settings. Dammer receives only "active", "idle" or "locked".

Each one is explained on the security and permissions page.

This website

This website has no analytics, cookies or tracking of its own. It is hosted on GitHub Pages and loads its fonts from Google Fonts and its animation libraries from the jsDelivr CDN, so those services receive the ordinary request data any web server does, such as your IP address. The live demo on the home page runs entirely in your browser.

Removing your data

Removing the extension from chrome://extensions deletes everything it stored. The Reset button in settings restores the defaults without removing the extension.

Changes to this policy

Any change is recorded in the changelog. A release that changed what Dammer can see or store would say so in its notes.

Contact

Questions: open an issue on GitHub. To report a security problem privately, see the security page.
