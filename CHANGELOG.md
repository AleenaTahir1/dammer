# Changelog

All notable changes to Dammer are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-12

First public release.

### Added

- Auto refresh for any open tab, chosen from a list and remembered between sessions.
- Randomised refresh intervals: four presets and a custom range from 30 seconds to 60 minutes.
- Digital and analog timer styles.
- Light, dark and glass themes with five accent colours; follows the system theme by default.
- Auto-stop after 1, 2, 4 or 8 hours.
- Automatic stop when the tab is closed, moves to a different site, or is sent to a login page.
- Pause while the tab is in front and the computer is in use.
- Protection from Chrome's Memory Saver for the chosen tab.
- Optional hard refresh and toolbar badge.
- `Alt+Shift+R` shortcut to start or stop from any tab.
- About page with the version number and developer links.
- End-to-end test suite that runs the extension in real Chrome.
