Install guide

Install Dammer in a minute.

Dammer is installed from a GitHub release. You download a small zip, unzip it and point your browser at the folder.

Download for Chromefree

Install in Chrome

  1. Download. Open the latest release and download dammer-1.0.2.zip.
  2. Unzip. Unzip it somewhere you will keep it, such as your Documents folder. Chrome loads the extension from this folder, so do not delete it afterwards.
  3. Open the extensions page. Type chrome://extensions in the address bar and press Enter.
  4. Turn on Developer mode with the switch in the top right corner.
  5. Load it. Click Load unpacked and choose the unzipped folder, the one that contains manifest.json.
  6. Pin it. Click the puzzle-piece icon in the toolbar and pin Dammer so its icon is always visible.

Edge, Brave, Arc and Opera

The steps are the same; only the address of the extensions page changes.

BrowserExtensions pageDeveloper switch
Microsoft Edgeedge://extensions"Developer mode", bottom left

Firefox and Safari are not supported.

Start your first timer

  1. Open the page you want refreshed.
  2. Click the Dammer icon in the toolbar.
  3. Under Tab, choose that page. Dammer remembers it, so you only do this once.
  4. Under Refresh every, choose a range in minutes, or Custom for anything from 30 seconds to 60 minutes.
  5. Press Start. The icon turns green and shows ON.

You can now switch to other tabs; the timer keeps running. Press Stop, or Alt+Shift+R from any tab, to end it. It also stops by itself after two hours unless you change the auto-stop time in settings.

Update

Download the newest zip, unzip it over the old folder, then click the reload arrow on Dammer's card on the extensions page. Your settings are kept. The changelog lists what changed.

Remove

Click Remove on Dammer's card on the extensions page. Everything it stored is deleted with it.

If something is not working

What you seeWhat to do
"Manifest file is missing or unreadable"You chose the wrong folder. Pick the folder that directly contains manifest.json.
A "Disable developer mode extensions" message when Chrome startsThis is Chrome's standard notice for extensions installed outside the Web Store. Close it; Dammer keeps working.
The Start button is greyed outNo tab is chosen. Open the Tab list and pick a page.
The page you want is not in the Tab listOnly ordinary web pages are listed. Browser pages such as chrome://settings cannot be refreshed.
Alt+Shift+R does nothingAnother extension may use the same keys. Set a different shortcut at chrome://extensions/shortcuts.
It says "Paused while you're on the tab"That is the setting protecting whatever you are typing. Switch to another tab, or turn the setting off.
