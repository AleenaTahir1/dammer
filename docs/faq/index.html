Frequently asked questions

Questions, answered.

How auto refresh works in Chrome, what Dammer can and cannot do, and how to keep it out of your way.

Getting started

How do I auto refresh a tab in Chrome?

Chrome has no built-in auto refresh, so you need an extension. With Dammer: click its icon, choose the page under Tab, choose a range under Refresh every, and press Start. The toolbar icon turns green and shows ON while it runs. The install guide has the full steps.

Is Dammer free?

Yes. Dammer is free and open source under the MIT licence. There is no account, no paid tier and no advertising.

Is Dammer on the Chrome Web Store?

No. You install it from a GitHub release by loading the unzipped folder in chrome://extensions with Developer mode switched on. It takes about a minute.

Which browsers does it work in?

Chrome 120 or newer, and other Chromium browsers: Microsoft Edge, Brave, Arc and Opera. It does not work in Firefox or Safari, and there is no mobile version.

Using it

Does it work on any website?

It works on any ordinary web page (addresses starting with http or https). It cannot refresh browser pages such as chrome://settings or the Chrome Web Store. Some websites do not allow automatic refreshing in their terms, so check before you use it on one.

What refresh intervals can I set?

Four presets (2–3, 3–5, 5–8 and 8–12 minutes) or a custom range from 30 seconds to 60 minutes. Each refresh happens at a random moment inside the range. Set both ends of a custom range to the same value if you want a fixed interval.

Can it refresh more than one tab at a time?

No. Dammer refreshes one tab at a time. Choosing a different tab while it is running moves the timer to that tab.

Does it keep refreshing when the tab is in the background?

Yes. The timer runs in Chrome itself, not inside the page, so it keeps working when you switch tabs or minimise the window, and Dammer stops Chrome's Memory Saver from putting the tab to sleep. Chrome has to be open, and refreshing pauses while the computer is asleep.

Will it reload the page while I am typing?

Not while you are using the tab. With Pause while I'm on the tab switched on (the default), Dammer skips a refresh whenever the tab is in front and the computer has been used in the last minute.

How do I stop it?

Press Stop in the popup, or press Alt+Shift+R from any tab. It also stops by itself after the auto-stop time (2 hours by default), when the tab is closed, when the tab moves to a different site, or when the site sends it to a login page.

What is the difference between the digital and analog timer?

Only how the countdown looks. Digital shows large numbers with a progress bar; analog shows a clock face whose hand sweeps round once per cycle. Switch between them in Settings.

Privacy and safety

Is Dammer safe to install?

It is designed so there is very little it could do even if it had a bug. It makes no network requests (the browser blocks them through its security policy), it has no access to the content of any page, and every line of code is public. The security page explains how to check this yourself.

Why does Chrome say it can "Read your browsing history"?

That is how Chrome describes the tabs permission. Dammer uses it to read the title and address of your open tabs so you can pick one from a list, and to notice when the chosen tab has moved to a different site. Nothing is sent anywhere. See permissions.

Can Dammer read my passwords or what is on a page?

No. It has no content scripts and no host permissions, so it cannot read or change the content of any page: not text, forms, passwords or cookies.

What does Dammer store?

Your settings and the tab you chose (its address without anything after a question mark), in your browser profile on your computer. Removing the extension deletes it all. The privacy policy lists every item.

Does it slow down my computer?

No. The background script sleeps between refreshes and wakes for a few milliseconds each cycle. The only real cost is the page itself reloading, exactly as if you pressed the reload button.

Updating and removing

How do I update Dammer?

Download the newest zip from the releases page, unzip it over the old folder, then click the reload arrow on Dammer's card in chrome://extensions. Your settings are kept.

How do I remove it?

Open chrome://extensions and click Remove on Dammer's card. Everything it stored is deleted with it.
